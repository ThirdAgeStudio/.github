# Third Age Studio

**Custom Shopify experiences your team can still edit.**

Third Age Studio is an independent Shopify studio. It builds interactive storefronts and product experiences for brands that have outgrown their theme, then hands them over so your own team can run them without calling a developer for every change. You work directly with the person who builds it.

### What I build

- **Interactive product experiences**: 3D product configurators, build-your-own flows, scroll-driven product storytelling
- **Custom theme sections and blocks**: Online Store 2.0 and Horizon, fully editable in Shopify's theme editor
- **Headless storefronts**: Next.js on Shopify's Storefront API, paired with a visual CMS so non-developers can still change layouts and campaigns
- **Store care**: audits, performance work and fixes for stores already in production

### Stack

Shopify (Liquid, theme blocks, metaobjects, Storefront and Admin APIs) · TypeScript · Next.js · React · three.js / `<model-viewer>` · GSAP · Builder.io · Node

Public demos and starter code live in this org. Client work stays private.
